# 바이옴 맵 생성 설계 (프로젝트 4/4)

작성일: 2026-08-06
상태: 방식 사전 승인(바이옴 밴드 + 노이즈), 세부 설계 문서

## 배경 (사용자 확정)

- 맵은 랜덤 생성되면 좋음 (시드 기반 유지)
- **멀리 날기(DIST)에서 진행 거리에 따라 주변 바이옴이 변하는 연출**
- 기존 "서버는 시드 하나만 동기화, 클라이언트가 결정론 생성" 아키텍처 유지
- 3D 자유각도 접기 프로젝트와 병행 — index.html 통합은 접기 UI 작업 완료 후 순차 진행

## 목표

7.5km 직선 협곡이 단조로운 단일 풍경에서 **5개 바이옴을 통과하는 여정**이 된다. 멀리 갈수록 세계가 변하는 시각적 보상. 배치도 균일 랜덤에서 노이즈 기반 리듬(좁아졌다 넓어지는 협곡, 밀집·희소 구간)으로.

## 비목표

- 서버 변경 (시드 프로토콜 그대로)
- 무한 맵·청크 스트리밍 (7.5km 고정 유지)
- 지형 메시 변경 (기존 InstancedMesh 박스/콘/바위 어휘 유지 — 색·밀도·크기 분포만 바이옴화)

## 1. 바이옴 정의 (`public/map-gen.js` 신규 순수 모듈)

Z(진행 거리, 0 → -7500)를 5개 밴드로 나눈다. 경계 ±150m 구간은 선형 블렌드.

| # | 구간 | 이름 | 하늘(top/mid/bottom) | 안개색 | 지형 색(벽/첨탑/바위) | 특성 |
|---|---|---|---|---|---|---|
| 0 | 0–1.5km | 사막 협곡 | 현행 파랑/살구 | 현행 | 현행 갈색 계열 | 기준 밀도 |
| 1 | 1.5–3km | 초원 숲 | 밝은 하늘/연두빛 | 연녹회색 | 이끼 녹색·암녹 | 첨탑 +30% (숲 기둥 느낌), 상승기류 + |
| 2 | 3–4.5km | 설원 | 창백한 하늘/흰빛 | 밝은 백청 | 눈덮인 회백·빙청색 | 공중 바위 +40%, 벽 높이 + |
| 3 | 4.5–6km | 화산재 | 어두운 주황/암적 | 붉은 회갈 | 현무암 흑갈·용암빛 강조 | 협곡 폭 -20% (좁고 위험), 링 보상 + |
| 4 | 6–7.5km | 하늘섬 새벽 | 보라/금빛 새벽 | 옅은 보라 | 창백한 부유암 | 벽 희소·공중 바위가 섬처럼, 상승기류 ++ |

모듈 API (UMD, Three.js 비의존, 서버 require 가능):

- `BIOMES` — 위 표의 데이터 (색은 hex number, 밀도는 배수)
- `sampleBiome(z)` → `{ a: biomeIndex, b: biomeIndex, t: 0..1 }` — 블렌드 구간이면 a≠b
- `makeNoise1d(seed)` → `f(z) ∈ [-1,1]` — 시드 값 노이즈(격자 보간, 옥타브 2)
- `buildDistanceLayout(seed)` → 결정론적 배치 데이터:
  - `walls: [{ side, x, z, w, h, d, biome }]` — 협곡 폭·벽 높이가 노이즈로 물결침 (`DIST_HALF` 기준 ±25% 폭 변조, 화산재 밴드 -20% 추가)
  - `spires / rocks / thermals / rings: [{ x, y?, z, r?, h?, biome }]` — 바이옴 밀도 배수 적용, 좌표는 협곡 폭 변조를 따름
  - 총량은 현행 수준 ±40% 내 (성능 보호: walls ≤ segs×2 유지, spires·rocks 상한 현행×1.5)
- `arenaTheme(seed)` → ARENA 방마다 바이옴 하나를 골라 그 팔레트 반환 (드롭인 방 시각 다양성 — 배치 로직 변경 없음, 색·안개만)

## 2. 클라이언트 통합 (index.html)

- `buildDistance(seed)`: 직접 rng 배치 대신 `buildDistanceLayout(seed)` 소비. InstancedMesh는 유지하되 **instanceColor**로 바이옴별 색 적용 (mesh 분리 없이 1드로우콜 유지).
- **바이옴 전환 연출**: 비행 루프에서 내 기체 z로 `sampleBiome`을 매 프레임 샘플 → `scene.fog.color`, 하늘 셰이더 uniforms(uTop/uMid/uBottom), 조명 색을 lerp. DIST에서만 동작.
- HUD에 현재 바이옴 이름 표시 (진입 시 2초 페이드 배지 — "설원에 진입했습니다").
- `buildArena(seed)`: `arenaTheme(seed)` 팔레트로 벽·첨탑·바위 색과 안개·하늘 적용 (배치 변경 없음).
- 중앙선·경계 링 등 가독성 요소는 불변.

## 3. 테스트

- 결정론: 같은 시드 → `buildDistanceLayout` 동일 결과(JSON 비교), 다른 시드 → 다른 결과
- 경계: 모든 배치물 z ∈ [-7500, 0], 벽 제외 장애물 |x| < 폭 변조 반영 한계, 링·상승기류 y 범위 현행 준수
- 바이옴: 각 밴드 중심 z에서 `sampleBiome`이 단일 바이옴, 경계에서 t ∈ (0,1); 밀도 배수가 실제 개수에 반영(±ε)
- 성능 상한: spires·rocks·walls 개수 상한 검증
- `arenaTheme` 결정론
- 시각 연출은 브라우저 검증
